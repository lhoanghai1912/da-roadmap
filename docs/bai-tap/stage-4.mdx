## Phần C — Bảng map SQL ↔ Pandas

Tự điền cột phải trước, rồi mở đáp án đối chiếu. Đây là bảng bạn sẽ dùng suốt sự nghiệp.

| SQL | Pandas |
|---|---|
| `SELECT a, b` | ? |
| `WHERE x > 1 AND y = 'z'` | ? |
| `GROUP BY a` | ? |
| `HAVING COUNT(*) > 5` | ? |
| `JOIN ... ON` | ? |
| `LEFT JOIN` | ? |
| `ORDER BY x DESC` | ? |
| `LIMIT 10` | ? |
| `COUNT(DISTINCT x)` | ? |
| `LAG(x)` | ? |
| `SUM(x) OVER (PARTITION BY g)` | ? |
| `ROW_NUMBER() OVER (PARTITION BY g)` | ? |
| `COALESCE(x, 0)` | ? |

<details>
<summary>Đáp án</summary>

| SQL | Pandas |
|---|---|
| `SELECT a, b` | `df[["a","b"]]` |
| `WHERE x > 1 AND y = 'z'` | `df[(df.x > 1) & (df.y == "z")]` — **bắt buộc có ngoặc** |
| `GROUP BY a` | `df.groupby("a")` |
| `HAVING COUNT(*) > 5` | `.groupby("a").filter(lambda g: len(g) > 5)` |
| `JOIN ... ON` | `pd.merge(a, b, on="key")` |
| `LEFT JOIN` | `pd.merge(a, b, on="key", how="left")` |
| `ORDER BY x DESC` | `.sort_values("x", ascending=False)` |
| `LIMIT 10` | `.head(10)` |
| `COUNT(DISTINCT x)` | `.nunique()` — **không phải `.count()`** |
| `LAG(x)` | `.shift(1)` |
| `SUM(x) OVER (PARTITION BY g)` | `.groupby("g")["x"].transform("sum")` |
| `ROW_NUMBER() OVER (PARTITION BY g)` | `.groupby("g").cumcount() + 1` |
| `COALESCE(x, 0)` | `.fillna(0)` |

</details>
